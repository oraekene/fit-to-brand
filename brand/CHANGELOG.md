# Changelog

All notable workflow changes are documented here.

## 0.3.0-agnostic

- Provider-agnostic: Lovart is now one supported Provider Profile, not an assumption
- New required Provider Profile & Tooling Adapter (image / video / layout / font source / cost unit / capabilities + fallbacks)
- `credit-consuming` generalized to resource-consuming (credits / tokens / API $ / render time)
- Generation Plan now records provider profile + cost + font source + capability workarounds
- Typography: Approved Font Source (Google Fonts default; Adobe / commercial / system allowed with confirmed license) instead of Google-Fonts-only
- Reasoning mode generalized (use deepest available; Thinking Mode is one example)
- URL-install generalized to any agent with web fetch; attachment note generalized
- Guideline 16:9 + text-rendering fallback for providers without aspect control
- Bonus C motion adapter: storyboard + shot-list fallback when no video generator
- Benchmark / bug template: PROVIDER PROFILE replaces LOVART MODE
- Fully backward-compatible: existing Lovart Thinking Mode runs work unchanged
