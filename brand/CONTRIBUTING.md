# Contributing

Thank you for helping improve Brand System Skill (provider-agnostic). This project benefits most from concrete, reproducible observations about how the workflow behaves on any provider profile (Lovart, Midjourney + LLM, GPT-image, Firefly, SD/ComfyUI, video generators, Figma/Canva AI, etc.).

## Useful contributions

- reproducible workflow bugs;
- unclear onboarding;
- missed approval gates;
- typography inconsistencies;
- Brand Lock failures;
- visual drift;
- benchmark reports;
- accessibility improvements.

For workflow bugs, use the **Skill bug** issue template. A useful report includes:

- Skill version;
- Provider profile (image / video / layout / font source + models) + agent & reasoning mode;
- loading method;
- workflow stage;
- expected behavior;
- actual behavior;
- skipped gates;
- manual intervention;
- benchmark category.

Describe the smallest reproducible sequence you can. Remove irrelevant generation history and include only the context needed to understand the behavior.

## Privacy and rights

Issues and contributions are public. Review every attachment and pasted excerpt before submitting it.

Do not submit:

- confidential client work;
- private conversations;
- personal data;
- credentials;
- unlicensed references;
- proprietary brand files.

By contributing, you confirm that you have the right to share the submitted material under the repository’s [CC BY 4.0 license](LICENSE).
